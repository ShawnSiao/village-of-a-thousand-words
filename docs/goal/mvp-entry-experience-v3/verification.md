# 《千字村》入口体验原型三试玩验证

## 验证范围

本次验证只使用原型内提供的信息，不读取外部玩法说明。完整走通标题页、职责说明、4 页序章、旧碑阅读、3 页玩法教学、前 5 回合和阶段总结。

验证环境：

- Codex 内置浏览器；
- 本地地址：`http://127.0.0.1:4311/千字村入口体验原型三/千字村入口体验.html`；
- 检查宽度：750、1280 和 1600 px。

## 路线一：公共身份与共同叙事

### 选择记录

1. 「东桥洪水」选择「预警记录」。
2. 「无籍之人」选择「村民记录」。
3. 「苦草之方」选择「传承记录」。
4. 「重修东桥」选择「共建记录」。
5. 压缩「前次洪水死者」，从「完整记录」改为「死亡人数」。
6. 接受祝婆托付，但为「祝婆的旧歌」选择「神话版本」。

### 验证结果

- 第 4 回合总字数达到 1001 字，编辑器显示「千字碑超出 1 字」。
- 「封存本年」保持禁用，旧记忆同时标记为「可整理」。
- 压缩旧记忆后，总字数降至 938 字，封存恢复可用。
- 第 4 回合能够回溯第 1 回合删去的救援记录，并说明私人记忆不能作为公共证据。
- 第 5 回合显示「红线断裂」，明确指出托付内容和违背方式。
- 阶段总结显示 960 / 1000 字、15 段现存记忆和 1 段碑外残响。

## 路线二：实用知识与谨慎承诺

### 选择记录

1. 「东桥洪水」选择「英雄记录」。
2. 「无籍之人」选择「水工记录」。
3. 「苦草之方」选择「药方记录」。
4. 「重修东桥」选择「工法记录」。
5. 压缩「开村记」，从「完整记录」改为「立碑规则」。
6. 不接受无法保证的托付，为「祝婆的旧歌」选择「接纳原则」。

### 验证结果

- 第 4 回合总字数达到 1013 字，编辑器显示「千字碑超出 13 字」。
- 压缩「开村记」后，总字数降至 951 字。
- 第 4 回合同时读取第 1 回合的救援关系和本回合的工程方法，形成不同于路线一的反馈。
- 未接受祝婆托付时，不显示红线状态，不把后续选择误判为违约。
- 阶段总结显示 979 / 1000 字，并呈现「英雄叙事」「临时居留」「无名药方」「工程方法」「接纳原则」组成的不同村庄。

## 理解与操作检查

| 检查项 | 结果 | 证据 |
| --- | --- | --- |
| 能否区分三种职责 | 通过 | 职责页分别说明守字人决定碑文、刻字匠更换碑片、守碑人维护碑身。 |
| 能否理解石碑更新 | 通过 | 序章说明固定碑身、替换碑片和磨平旧文。 |
| 能否理解红线作用 | 通过 | 托付出现时说明承诺内容；选项显示完整、松动和断裂的预期结果。 |
| 超限后能否找到下一步 | 通过 | 顶部警示、左栏「可整理」标签和「先整理」按钮同屏出现。 |
| 后果能否回溯 | 通过 | 每轮固定显示保留、删去、知情者、未来影响和来源回合。 |
| 玩家可见语言 | 通过 | 两条路线的阶段总结未出现英文内部标识符。 |
| 窄屏和宽屏是否溢出 | 通过 | 750、1280 和 1600 px 均未出现横向溢出。 |
| 字号是否满足底线 | 通过 | 固定正文不小于 16 px，次要标签不小于 14 px。 |

## 试玩中完成的修正

- 标题页结语改为单行宽度，避免宽屏末尾孤字。
- 职责页取消桌面端双重滚动条，窄屏恢复自然页面滚动。
- 「碑片更替」标题增加真实文字遮罩和固定换行，不再与图片装饰文字重叠。
- 玩法教学页允许纵向滚动，低高度视口仍可到达「进入第一回合」。
- 样式和脚本增加版本参数，避免本地刷新继续读取旧文件。

## 当前结论

前 5 回合已经能够表达核心命题：公共记忆不是事实仓库，而是会决定资格、信任、知识传承和共同信仰的制度。两条路线均出现明确的策略收益和情感损失，压缩比直接删除更容易产生犹豫。

当前原型仍不能验证完整 15 回合的节奏、最终洪水的综合结算和多周目长期差异。回合 6～15 应继续复用现有因果结构，不在入口原型中增加新的状态系统。
